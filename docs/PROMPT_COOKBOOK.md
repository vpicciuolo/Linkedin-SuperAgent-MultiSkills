# Prompt cookbook

## Foundation

```text
Use linkedin-voice-lab. Compare these eight posts, quote the evidence for every voice rule, and mark uncertain rules as provisional.
```

```text
Use linkedin-story-bank. Interview me about a failed rollout, but protect the client name and any confidential metrics.
```

```text
Use linkedin-strategy. My audience is GCC retail operations leaders. Build a 30-day strategy from my proof and six-hour monthly time budget.
```

## Content

```text
Use linkedin-hook-lab. Give me six openings for this case study, explain the promise each makes, and reject any the body cannot fulfill.
```

```text
Use linkedin-post-writer. Draft one post from this interview note. Keep the uncertainty and leave unknown numbers as NEEDS INPUT.
```

```text
Use linkedin-carousel. Turn this process into an eight-page document post with page copy, visual direction, and accessibility notes.
```

```text
Use linkedin-newsletter. Build an issue for founders about the decision, evidence, limitations, and practical next step in this research.
```

```text
Use linkedin-repurposer. Extract a ranked asset map from this webinar transcript, then write only the strongest post.
```

## Engagement and profile

```text
Use linkedin-comment. Draft two comments that add something new to this post. Do not praise generically or mention my product.
```

```text
Use linkedin-reply. Triage this thread and write replies only where they help readers or continue a real conversation.
```

```text
Use linkedin-dm. Write a connection note for this person based only on the context I provide. Flag anything that sounds assumed.
```

```text
Use linkedin-profile. Score only the visible sections, cite every deduction, and rewrite the three highest-impact areas.
```

## Analytics and teams

```text
Use linkedin-analytics. Analyze this CSV for conversation and follow conversion. Report missing data and avoid causal claims.
```

```text
Use linkedin-campaign. Plan a four-week report launch with message hierarchy, asset owners, approvals, and measurement.
```

```text
Use linkedin-employee-advocacy. Create a voluntary 14-day pilot where each employee writes from their own experience.
```
